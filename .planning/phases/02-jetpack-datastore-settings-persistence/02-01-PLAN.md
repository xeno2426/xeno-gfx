## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Disk Storage -> SettingsRepository Flow | Unserialized preferences protobuf read from private application files directory |
| Presentation Layer -> SettingsRepository Mutations | Async coroutine calls on Dispatchers.IO mutating shared preferences state |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Denial of Service | SettingsRepository / Disk I/O | medium | mitigate | Catch IOException in dataStore.data.catch operator and emit emptyPreferences() to prevent application crash on disk corruption or permission read error per D-07 |
| T-02-02 | Denial of Service | SettingsRepository / Thread Safety | high | mitigate | Confine all DataStore edit transactions and Flow mapping to Dispatchers.IO using withContext(ioDispatcher) and flowOn(ioDispatcher) to prevent Main Looper thread starvation per D-08 |
| T-02-SC | Tampering | Google Maven dependency install | high | mitigate | Package legitimacy gate verified in RESEARCH.md: androidx.datastore:datastore-preferences:1.1.3 is official AndroidX library with verdict [OK] |
</threat_model>
