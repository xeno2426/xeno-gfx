| Android Framework -> Context Receiver (Battery) | External OS broadcasts delivered to app; requires explicit export flags |
| Core Repository -> Network (Google DNS 8.8.8.8:53) | Socket connection to remote IP; potential network timeouts and socket exhaustion |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Spoofing / Tampering | Battery Broadcast Receiver | medium | mitigate | Register receiver using ContextCompat.RECEIVER_NOT_EXPORTED on API 34+ and clamp received temperature to 0.0C..80.0C |
| T-01-02 | Denial of Service | Network Socket Probe | medium | mitigate | Wrap socket creation in Socket().use { ... } with 500ms connection timeout on Dispatchers.IO to prevent socket exhaustion |
| T-01-04 | Information Disclosure | Latency Socket Probe | low | accept | Connects only to public Google DNS (8.8.8.8:53) without user payload; measures TCP handshake RTT only |
| T-01-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package legitimacy gate verified; zero third-party dependencies added |
</threat_model>
