## Critical Anti-Patterns (do NOT repeat these)
- [SUBAGENT TIMEOUT]: Subagents prompt-timing out on filesystem writes → instruct subagents to return complete markdown content in final completion message and have parent orchestrator persist files.
- [JAVA 25 EA INCOMPATIBILITY]: Gradle daemon incompatibility with Java 25 EA → org.gradle.java.home set permanently in gradle.properties to Java 21 (/usr/lib/jvm/java-21-openjdk-amd64).
- [MAIN LOOPER DATASTORE BLOCK]: Calling runBlocking or synchronous disk I/O on Main Looper → always dispatch DataStore reads/writes on Dispatchers.IO or serviceScope/viewModelScope.
