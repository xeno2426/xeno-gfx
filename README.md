# Xeno GFX

A game performance toolkit for Android.

## Features (Planned)

- 🎮 **Game Detection** — Automatically detect when a game is launched
- 📊 **Floating HUD** — Live overlay showing FPS, CPU, RAM, battery & temperature
- ⚡ **GFX Optimization** — Per-game graphics configuration profiles
- 🌐 **Network Monitor** — Real-time latency and connection quality
- 📈 **Session Tracking** — Post-game performance summaries and history

## Tech Stack

- **Language:** Kotlin
- **Min SDK:** 26 (Android 8.0)
- **Target SDK:** 35 (Android 15)
- **UI:** Jetpack Compose + Material 3
- **Architecture:** MVVM with Clean Architecture
- **DI:** Hilt
- **Local Storage:** Room + DataStore

## Building

```bash
./gradlew assembleDebug
```
